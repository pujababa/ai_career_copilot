# 🚀 AI Career Copilot
### AI-Powered Career Guidance & Placement Preparation Platform

AI Career Copilot is a web-based platform designed to help students prepare for placements, analyze their career readiness, track job applications, and improve their technical skills using AI-powered assistance.

🌐 **Live Demo:** [AI Career Copilot](https://ai-career-copilot-rwi0.onrender.com)

---

## ✨ Key Features

- 🤖 **AI Career Chat** — AI-powered career guidance and placement assistance.
- 🎯 **Career Assessment** — Explore career options based on your interests and skills.
- 📄 **Resume Tools** — Resume analysis and career document assistance.
- 💼 **Job Match Analyzer** — Evaluate how your skills align with job requirements.
- 📊 **Placement Tracker** — Track applications and placement progress.
- 🧠 **Skill Gap Analysis** — Identify skills to improve for your target role.
- 📚 **Learning Resources** — Support your technical learning and preparation.
- 💻 **Coding & Aptitude Practice** — Practice programming, aptitude, and technical questions.
- 👨‍💼 **Admin Dashboard** — Manage users and platform activities.
- 🔐 **Authentication System** — Separate student and administrator access.

## ⚙️ Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/pujababa/ai_career_copilot.git
cd ai_career_copilot
```

### 2. Create and activate a virtual environment

```bash
python -m venv venv
```

Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure environment variables

Create a `.env` file in the project root and configure the required environment variables, including your Gemini API key and Flask secret key.

**Security:** Never commit `.env`, API keys, passwords, or private credentials to GitHub.

### 5. Start the application

```bash
python app.py
```

Open the local URL shown in the terminal.

## 🔒 Security

- Keep API keys and secret credentials in environment variables.
- Do not upload private database files or credentials to a public repository.
- Use secure authentication and production configuration.
